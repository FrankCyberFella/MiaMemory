# Family photos

Drop photo files in this folder (e.g. `mom.jpg`, `dad.jpg`, `grandma.jpg`),
then add each filename to `family-photos-manifest.js` in the project root.
They'll show up automatically in the app's Family theme on startup — no
upload needed.

## Recommended photo specs

- Roughly square framing — the app center-crops to a square card, so
  square-ish source photos avoid faces getting cut off
- At least 600×600px
- JPEG format, ideally under 300–500KB each, so the app stays fast to load
- Simple filenames: `mom.jpg`, `dad.jpg`, `grandma.jpg`, `grandpa.jpg`, etc.

## Heads up

This is a public GitHub Pages project. Any photo placed here is published
along with the rest of the site and is visible to anyone with the URL.
